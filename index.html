NadaPlan · 10K aguas abiertas

Generador de rutinas — estructura ENT CAL · ACT · TPPAL · FINAL, ciclos de 4 semanas con progresión

AGREGAR FUENTE

Guardá acá rutinas que consigas de otros lados (entrenadores, videos, revistas). Quedan como biblioteca de consulta para armar variantes nuevas.

MI BIBLIOTECA

MIS BLOQUES DEL GENERADOR

Los bloques que cargues acá entran en la rotación del generador junto a los de fábrica: aparecen en tus rutinas (marcados con ★), con los tiempos "incluido" calculados desde tu R1 y ajustados por semana y ciclo. Es la forma de convertir una fuente en variantes reales.

PANEL DE ADMINISTRACIÓN

Solo vos ves esta pestaña. Desde acá podés ver todos los usuarios y eliminar sus datos. Para eliminar también la cuenta de autenticación, hacelo desde Firebase Console → Authentication → Users.

CARGAR TEST — 3x200 NEGATIVO

El test aparece en la rutina de la Semana 1 · Sesión 3 de cada ciclo. Cargá los tres tiempos (mm:ss) apenas termines; la app calcula tu ritmo promedio /100 y te sugiere el nuevo R1.

SESIONES COMPLETADAS

MIS PARÁMETROS

De tu R1 salen R2 (~8 % más rápido) y R3 (~15 % más rápido). El tiempo disponible define cuántos metros entran. El peso se usa para estimar las calorías de cada sesión (~0,25 kcal/m ajustado a tu peso).

POSICIÓN EN EL PLAN

Moverte no registra nada: solo cambia qué sesión ves. Para registrar y avanzar usá "Sesión completada" en la rutina.

RESPALDO

Los datos se guardan automáticamente en Firebase (nube). El JSON de exportar/importar sirve como respaldo adicional.

CONFIGURAR FIREBASE (una sola vez)

Ver instrucciones de setup ▸
1. Entrá a console.firebase.google.com y creá un proyecto nuevo (ej: "nadaplan")
2. En el menú izquierdo: Authentication → Get started → Sign-in method → Email/Password → Habilitar → Guardar
3. En el menú izquierdo: Firestore Database → Create database → Start in production mode → Elegir ubicación (la que quieras) → Create
4. En Firestore → Rules, reemplazá todo por esto y publicá:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId} { allow read, write: if request.auth != null && request.auth.uid == userId; } } } 5. En Project settings (engranaje arriba a la izquierda) → Your apps → Web (ícono </>) → Poné un nombre → Register app
6. Copiá el bloque firebaseConfig que te muestra y pegalo en el archivo index.html reemplazando el bloque que dice "TU_API_KEY" etc.
7. Subí el archivo actualizado a GitHub y listo — cada persona crea su usuario desde la pantalla de login.
